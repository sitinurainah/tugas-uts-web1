# tugas-uts-web1

Toko Buku Aksara.


Platform web interaktif untuk pengelolaan katalog buku ajar, pemesanan, dan pelacakan pengiriman paket secara terpusat.



Fitur Utama:

- Autentikasi dan Dashboard: Sistem login (User/Admin) dan dashboard interaktif yang menampilkan ringkasan data statistik sistem seperti jumlah judul buku, total stok, dan pesanan aktif.

- Katalog dan Stok Buku: Menampilkan daftar lengkap buku ajar, fitur pencarian instan (live search), serta penambahan data buku baru secara dinamis menggunakan JavaScript DOM.

- Pemesanan (Checkout): Formulir pemesanan buku dengan pilihan kuantitas dan metode pembayaran fleksibel (Transfer Bank, Virtual Account, COD).

- Lacak Pengiriman: Fitur pelacakan status pesanan berdasarkan nomor Delivery Order (DO) lengkap dengan timeline perjalanan paket.



Teknologi yang Digunakan:

- HTML5 dan CSS3 untuk desain responsif dan kustom antarmuka.

- JavaScript (Vanilla JS) untuk manipulasi DOM, pencarian, dan manajemen data sesi.



Struktur Folder Proyek:

tugas-uts-web1/

- assets/ (Aset gambar dan logo)

- css/ (Lembar gaya style.css)

- js/ (Berkas logika dan data seperti script.js dan data.js)

- index.html (Halaman Login)

- dashboard.html (Halaman Dashboard)

- stok.html (Halaman Katalog dan Stok)

- checkout.html (Halaman Pemesanan)

- tracking.html (Halaman Lacak Pengiriman)
